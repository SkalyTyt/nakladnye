# Приёмка накладных

Приложение превращает Excel-накладные поставщиков в аккуратную таблицу для Контур.Маркета.

## Как запустить
- Онлайн, в том числе с телефона: https://skalytyt.github.io/nakladnye/ (кнопка «Открыть пример» показывает работу на демо-файлах).
- На компьютере: откройте `index.html` двойным кликом (лучше в Chrome или Edge). Установка и интернет не нужны.

## Что умеет
- Сама находит таблицу товаров: ТОРГ-12, УПД и простые накладные, несколько накладных в одном файле.
- Сверяет сумму с «Итого» из файла.
- Объединяет два файла: накладная с ценами + файл с названиями и штрихкодами. Совпадения ищутся по коду, по названию и по похожему названию (такие помечаются «Проверить»). Товары с разными цифрами в названии (например, «Краска 501» и «Краска 502») не путаются.
- Справочник: запоминает пару «название → штрихкод» для каждого поставщика при выгрузке. В следующий раз штрихкоды подставятся сами.
- Настройки: вручную выбрать столбцы и строку заголовка (сохраняется для поставщика), выбрать и переименовать столбцы выгрузки.

## Файлы
- `index.html`: интерфейс и стили
- `app.js`: логика экрана
- `parser.js`: распознавание накладных и подбор штрихкодов
- `vendor/xlsx.full.min.js`: библиотека SheetJS 0.20.3 для Excel
- `demo/`: вымышленный счёт и файл со штрихкодами (`node tests/make-demo.js`)
- `tests/test.js`: проверки (`node tests/test.js`)

Настройки и справочник хранятся в браузере. Чтобы перенести их на другой компьютер, используйте «Справочник → Сохранить в файл».
